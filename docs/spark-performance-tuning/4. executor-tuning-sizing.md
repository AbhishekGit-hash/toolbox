**Starting Point**
5 Node Machines. Per Node Config: 12 Cores, 48 GB RAM

### Step 1: Leave 1 Core, 1 GB for Hadoop/YARN/OS Deamons

So, now left with: <br>
5 Node Machines. Per Node Config: 11 Cores, 47 GB RAM

### Step 2: At cluster level leave 1 core, 1 GB or an executor for YARN Application Master

For the total cluster:<br>
- Total cores  = 5 * 11 = 55 cores<br>
- Total Memory = 5 * 47 = 235 GB<br>

YARN AM gets 1 core and 1 GB. So the actual config for the cluster is:<br>
- Total cores = 55 - 1 = 54 cores<br>
- Total Memory = 235 - 1 = 234 GB<br>

### Step 3: Take number of cores per executor as 3 - 5 for good HDFS throughput

Say, number of cores per executor = 5.<br>

- number of executors = Total cores / number of cores per executor = 54 / 5 ~ 10 executors
- memory per executors = Total memory / number of executors = 234 / 10 ~ 23 GB

### Step 4: Give some memory to MemoryOverhead = Max(384 MB, 10% of spark.executor.memory)

actual memory per executor = 23 GB - Max(384 MB, 10% of spark.executor.memory) = 23 - max(384 , 0.1 * 23) = 23 - 2.3 ~ 20 GB
