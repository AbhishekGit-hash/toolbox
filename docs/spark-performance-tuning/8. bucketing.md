## Bucketing

### 1. Optimal number of buckets

Size of dataset = X GB <br>
Optimal bucket size = 128 MB - 256 MB <br>

```
NUM_BUCKETS = Size of dataset / Optimal bucket size
```


### 2. Bucketing in Joins

hash(product_id) % NUM_BUCKETS = [0, NUM_BUCKETS)

```python
from pyspark.sql import SparkSession

spark = (
    SparkSession.builder
    .conf("spark.driver.memory", "10g")
    .master("local[*]")
    .getOrCreate()
)

orders_file = "../data/bucketing/orders.csv"
df_orders = spark.read.csv(orders_file, header=True, inferSchema=True)

products_file = "../data/bucketing/products.csv"
df_products = spark.read.csv(products_file, header=True, inferSchema=True)

# Bucket datasets on product_id

(
    df_products
    .write.bucketBy(4, col="product_id")
    .mode("overwrite")
    .saveAsTable("products_bucketed")
)

(
    df_orders
    .write.bucketBy(4, col="product_id")
    .mode("overwrite")
    .saveAsTable("orders_bucketed")
)

df_orders_bucketed = spark.table("orders_bucketed")
df_products_bucketed = spark.table("products_bucketed")

df_orders_product_details_bucketed = (
    df_orders_bucketed.join(
        df_products_bucketed,
        on="product_id",
        how="inner"
    )
)
```

### 3. Bucketing in Aggregations

```python
df_product_sales = (
    df_orders_bucketed
    .groupBy("product_id")
    .agg(F.sum("total_amount").alias("sales"))
)

df_product_sales.explain()
```

### 4. Bucket Pruning (Filter)

hash is applied on the filter condition to get the bucket number so that unwanted bucket scanning is skipped.<br>

```python
df_product_sales_bucket_pruning = (
    df_orders_bucketed
    .filter(F.col("product_id") == 1)
    .groupBy("product_id")
    .agg(F.sum("total_amount").alias("sales"))
)
```
